# Freestyle Ski

**Play it in your browser: https://ianleitgeb.github.io/Airborne-Freestyle/**

A freestyle skiing game made in Unity: moguls, aerials, park jumps, rails, the cliff and more. Press UP to start a
run; the Settings button in the top right lists every control for wherever you are.

This repo only holds the game's web build (served by GitHub Pages). It plays best on a desktop browser with a keyboard
(or a controller on the aerials).
